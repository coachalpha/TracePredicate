
### 📊 组件权重与最终定义:

**Device Complexity** (20% 权重):
- 定义: 设备复杂性 = 510(k)提交密度
- 依据: 更多510(k)提交表明设备类型的监管复杂性

**Safety Impact** (40% 权重):
- 定义: 安全影响 = MAUDE不良事件密度
- 依据: 不良事件密度直接反映真实安全风险

**Event Severity** (25% 权重):
- 定义: 事件严重性 = 基于MAUDE与510(k)比值的严重性评估
- 依据: 高比值表明设备投入使用后出现更多问题

**Recall Severity** (15% 权重):
- 定义: 召回严重性 = FDA召回密度与频率
- 依据: FDA召回反映监管层面的安全关切
